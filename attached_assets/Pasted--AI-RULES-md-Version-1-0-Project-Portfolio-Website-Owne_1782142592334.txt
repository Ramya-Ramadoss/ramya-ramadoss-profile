JavaScript when TypeScript is required.

Never use inline styles.

Never hardcode colors.

Never hardcode spacing.

Never duplicate logic.

Never ignore TypeScript errors.

Every component must

Have one responsibility.

Receive typed props.

Be reusable.

Avoid unnecessary state.

Avoid duplicated logic.

Use composition where appropriate.

# 8. Styling Rules

Use Tailwind CSS.

Use design tokens.

Use centralized color definitions.

Maintain consistent spacing.

Avoid arbitrary pixel values.

Never introduce inconsistent UI styles.

# 9. Animation Rules

Use

Framer Motion

GSAP

Three.js

Only where appropriate.

Animations must

Improve UX.

Support storytelling.

Remain performant.

Respect reduced motion.

Never animate simply for decoration.

---

# 10. Three.js Rules

Three.js should remain isolated.

Scene logic belongs inside dedicated scene components.

Never mix Three.js rendering with business logic.

Lazy load heavy scenes.

Dispose resources correctly.

Maintain 60 FPS wherever possible.

Performance is a non-negotiable requirement.

Target

Performance Score

95+

Accessibility

95+

SEO

100

Best Practices

95+

AI must

- Lazy load heavy components.
- Lazy load Three.js scenes.
- Optimize images.
- Optimize fonts.
- Use dynamic imports where appropriate.
- Minimize JavaScript bundles.
- Avoid unnecessary re-renders.
- Memoize expensive computations only when beneficial.

Never sacrifice maintainability for micro-optimizations.
